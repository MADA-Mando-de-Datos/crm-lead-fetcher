B2B Lead Mining from Multiple Data Sources

DENUE (INEGI) • Yelp Fusion • Google Places

Lead Mining CRM generates qualified sales leads directly from your CRM by querying multiple public business directories. Select a source, configure the filters, and generate opportunities pre-tagged with sector, category and location.

Three Powerful, Pluggable Sources

  • DENUE (INEGI): official free directory of Mexican business establishments. Search by state, SCIAN sector, activity, business name or geographic radius.
  • Yelp Fusion API: businesses with reviews and ratings. Filter by category, price, rating, reviews, "open now", services and attributes.
  • Google Places API: global business directory from Google Maps. Multi-type text search, price range, minimum rating and "open now" filters.

Key Features

  • Extensible architecture: add new sources easily.
  • Wizard with source-specific filters and validation.
  • Advanced filters: sector, type, size (employee stratum), location, rating, price, service availability.
  • Automatic tagging by sector, category and place type.
  • Deduplication by external ID (DENUE ID, Yelp ID, Place ID).
  • Cross-source deduplication by business fingerprint (name + location / phone) to avoid duplicate leads from different sources.
  • Automatic assignment to sales team and salesperson.
  • Website-based email enrichment with one click.
  • CSV export of every mined lead.
  • Persisted business data: rating, review count, price level, GPS coordinates.
  • Connection testing and dashboard per source.

Installation Notes

This module requires external service credentials to fetch data, configured in Settings → CRM → Lead Mining:

  • DENUE (INEGI): free token available from the INEGI portal.
  • Yelp Fusion: free / paid API key from Yelp developers.
  • Google Places: API key with the Places API enabled from Google Cloud Console.

The module works fully in Community Edition. Data sent to the external services (search terms and your configured location) is limited to what is needed to execute the search you initiate.
